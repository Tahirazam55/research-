## 📌 Overview

This project presents a comparative analysis of how preprocessing strategies, regularisation techniques, and class imbalance handling affect the generalisation performance of epileptic seizure prediction models using EEG data. Three different datasets were used, including raw EEG signals, structured multichannel features, and high-dimensional time-series data, to evaluate model behavior under varying conditions. A Logistic Regression model was selected as a baseline to isolate the impact of data processing and training strategies. Two preprocessing pipelines were designed and compared: one focusing on normalization, noise removal, and feature selection, and the other using dimensionality reduction through PCA. The study further investigates L1, L2, and Elastic Net regularisation, along with oversampling techniques such as SMOTE, to understand their interaction with noisy and imbalanced data. The results highlight that preprocessing order significantly influences performance, L1 regularisation consistently improves generalisation through sparsity, and imbalance handling must be combined with regularisation to avoid overfitting caused by synthetic data.
